## 🚀 How to Navigate This Repo
1.  **Clone the repo:**
    ```bash
    git clone https://github.com/ankoolsrivastava/javaDsa.git
    ```
2.  **Navigate to a topic/step:** The folders are organized directly mirroring the Striver sheet steps.
3.  **Compile and Run:** Every file contains the main method required to test the logic. 
    ```bash
    javac ClassName.java && java ClassName
    ```
